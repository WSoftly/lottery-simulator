# 彩票模拟选号开奖系统

## 项目简介

这是一个模拟中国福利彩票双色球和体育彩票大乐透的选号、开奖及中奖概率分析的系统。用户可以：

- 查看两种彩票的中奖概率和奖金规则
- 手动或随机选择号码
- 模拟开奖过程
- 查看中奖结果统计

## 功能特点

### 1. 概率分析

- 详细展示双色球和大乐透各奖项的中奖概率计算公式
- 直观显示各奖项的中奖概率百分比
- 提供总中奖概率对比

### 2. 选号功能

- **手动选号**：点击选择红球/前区和蓝球/后区
- **机选功能**：
  - 机选红球/前区
  - 机选蓝球/后区
  - 机选一注
  - 批量机选5注
- **选号管理**：
  - 重置当前选号
  - 删除已选号码
  - 查看/修改开奖号码

### 3. 开奖模拟

- 随机生成开奖号码
- 自动比对用户所选号码
- 显示中奖结果和奖金统计
- 其中浮动奖奖金模拟为固定范围随机值

## 技术实现

- **前端**：HTML5, CSS3, JavaScript
- **响应式设计**：适配不同屏幕尺寸
- **交互效果**：平滑滚动、动画过渡等增强用户体验

## 使用说明

1. 首页查看彩票规则和概率分析
2. 点击"双色球模拟"或"大乐透模拟"进入相应模拟器
3. 选择号码：
   - 手动点击号码球选择
   - 使用机选功能快速生成号码
4. 确认选号后，点击"开奖"按钮
5. 查看开奖结果和中奖情况
6. 鼠标双击相应区域删除已选号码或修改查看开奖号码

## 注意事项

- 本项目仅为概率模拟和娱乐用途
- 不涉及真实金钱交易
- 实际彩票开奖为随机过程，本模拟结果仅供参考
